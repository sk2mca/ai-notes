GUIDE

Adding a new reference page

Follow these steps each time a new tool or concept reference is created

  • Create the new reference page using the same card-based template.
  • Add a new row under the appropriate section (Tools / Concepts / Processes) in this index.
  • Update the href to point to the new page's filename.
  • Set the status dot to Done once the reference notes are complete.
  • Replace the placeholder badge WIP with the correct type badge (TOOL, CONCEPT, or PROCESS).
